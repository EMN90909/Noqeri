# noqeri editor support

The canonical source extension is `.noqeri`. The wolf/code mark in `Brand/` is reused for official editor identity.

- `vscode/` — language registration, TextMate grammar, snippets, language config and file-icon theme.
- `jetbrains/` — TextMate/LSP setup notes.
- `vim/` — Vim/Neovim filetype and syntax definitions.
- `sublime/` — Sublime Text syntax definition.
